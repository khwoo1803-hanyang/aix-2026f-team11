## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
카카오톡, 디스코드, 최대 4시간 이내로 응답하기


## 회의 규칙 / Meeting rule — 요일·시간·불참 처리

매주 목요일 공강 시간 회의/ 목요일 상세한 시간은 상황에 맞게 조정/ 불참 시 사전에 미리 공지해주거나 부득이 하게 불참하게 된 경우 참여 인원이 불참한 인원에게 해당 주의 내용을 설명해서 마감 기한에 주 작업 끝낼 수 있도록 하기

## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량

기본 주에 인당 50% * 주마다 팀원의 상황에 맞게 유동적이게 조정

## 갈등 처리 / Conflict rule — 의견이 갈릴 때
서로 갈등인 부분에 대해 어떤 점 때문에 다르게 생각했는지 설명하고 작업에서의 중요도를 파악하여 좀 더 중요도에 비중이 큰 의견으로 채택


## 마감 규칙 / Deadline rule

메주 일요일 오후 11시 59분까지 팀장이 마감할 수 있게 보내주기

## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어

한국어

## AI 사용에 대한 팀 합의 / Team agreement on AI use

클로드와 같은 AI는 코드 초안·검색·문서 정리 등 반복 작업에 활용하고 최종 검토와 테스트는 팀원이 직접 하기, 개인정보나 민감한 내용은 입력하지 않기, AI가 만든 결과물이라도 제출 책임은 작성한 팀원에게 있음

## 성찰 / Reflection — 가장 걱정되는 것

타 팀에 비해 인원이 많지 않아 의견이 너무 달라 혼잡할 상황은 없을 것이라 생각하지만 인원이 적은 만큼 작업에 대한 개인의 노력과 책임이 클 것이라 생각됨
