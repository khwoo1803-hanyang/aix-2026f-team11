## ① 주제 선택 / Choosing one problem

| 항목 Item | 내용 |
|---|---|
| 선택한 주제 Chosen | 친구들이 여행방에서 채팅하면 AI가 대화 속 여행 조건(날짜·기간·인원·이동수단·예산·하고 싶은 것)을 정리해 여행지를 추천하고, 채팅 안에서 함께 투표해 정하는 여행 계획 앱 |
| 선택 근거 Why | 여러 명이 함께 여행을 계획할 때 의견이 단톡방 메시지 사이에 흩어져, 한 사람이 다시 읽고 정리해야 하고 결정이 미뤄짐. 기존 여행 앱은 일정 편집은 함께 할 수 있지만, 의견을 모으고 정하는 과정은 다시 카카오톡에서 해야 함 |

## ② 성공 기준 가져오기 / Success criteria from Week 3

| 3주차 성공 기준 원문 Original (Week 3) | 모호한 표현 Vague words |
|---|---|
| 친구들이 단톡방을 다시 뒤지거나 한 사람이 따로 정리하지 않아도, 대화한 내용을 바탕으로 여행지를 함께 정할 수 있도록 돕는다 | "대화한 내용을 바탕으로" — 대화의 어떤 내용을 쓰는가? (→ 날짜·기간, 인원, 출발지, 이동수단, 예산, 하고 싶은 것 6가지로 정함) |
|  | "여행지를 함께 정할 수 있도록" — 무엇이 되면 정해진 것인가? (→ 멤버 투표 후 방장이 확정하면 모든 멤버 화면에 여행지가 표시되는 것) |
|  | "다시 뒤지지 않아도" — 얼마나 빨리, 어디에 보여야 하는가? (→ 조건이 나온 메시지와 함께 30초 안에 채팅방 상단에 표시) |

## ③ Acceptance Criteria

최소 정상 경로 2개 + 실패 경로 1개. **판정 방법** 칸이 비면 아직 명세가 아닙니다.
At least two normal paths + one failure path. If "How to check" is empty, it is not yet a spec.

| # | 경로 Path | EARS 문장 Sentence | 판정 방법 How to check |
|---|---|---|---|
| *예시* | *정상* | *WHEN 학생이 과제 목록을 열면 THE 시스템은 SHALL 과목별 미제출 과제를 마감일 순으로 표시한다* | *미제출 과제 3건을 만든 뒤 목록을 열어 마감일 순으로 나오는지 확인* |
| AC-1 | 정상 Normal | WHEN 여행방 멤버가 날짜·기간, 인원, 출발지, 이동수단, 예산, 하고 싶은 것 중 하나가 담긴 메시지를 보내면 THE 시스템은 SHALL 30초 이내에 채팅방 상단 조건 바에 그 조건을 표시하고, 조건을 누르면 근거가 된 메시지를 보여준다. | 날짜·기간, 이동수단, 예산, 하고 싶은 것이 하나씩 들어간 시연용 메시지 4개를 3개 계정으로 나눠 보낸 뒤, 30초 안에 이 4개와 인원(3명)이 조건 바에 뜨는지, 각 조건의 근거 메시지가 실제로 그 내용을 말한 메시지인지 확인 |
| AC-2 | 정상 Normal | WHEN 멤버가 조건 확인 화면에서 '이 조건으로 여행지 추천받기'를 누르면 THE 시스템은 SHALL 15초 이내에 여행지 3곳을, 각 여행지가 만족하는 조건 수(예: 6/6)와 이유 한 줄과 함께 표시한다. | 조건 6개가 정리된 여행방에서 버튼을 누르고 15초 안에 3곳이 뜨는지, 3곳 모두 조건 수와 이유가 표시되는지 확인 |
| AC-3 | 정상 Normal | WHEN 방장이 채팅방의 여행지 투표 결과를 보고 한 곳을 확정하면 THE 시스템은 SHALL 5초 이내에 모든 멤버의 화면에 확정된 여행지를 표시한다. | 3개 기기로 투표한 뒤 방장 기기에서 확정을 누르고, 나머지 2개 기기에 5초 안에 여행지가 바뀌는지 확인 |
| AC-4 | 실패 Failure | IF 대화에 근거가 되는 메시지가 없는 조건(예: 출발지)을 AI가 추정해서 채우면 THEN THE 시스템은 SHALL 그 조건을 '확인 필요'로 표시하고, 멤버가 확인하기 전까지 근거 메시지 칸을 비워 둔다. | 출발지를 한 번도 말하지 않은 대화로 조건 정리를 실행해, 출발지가 '확인 필요'로 표시되고 근거 메시지가 없는지 확인 |
| AC-5 | 실패 Failure | IF 여행방 멤버가 아닌 사용자가 그 여행방의 채팅이나 조건을 요청하면 THEN THE 시스템은 SHALL 요청을 거부하고 내용을 하나도 보여주지 않는다. | 멤버가 아닌 테스트 계정으로 여행방 ID를 직접 넣어 채팅을 요청해, 메시지가 하나도 오지 않고 거부되는지 확인 |
| AC-6 | 실패 Failure | IF AI 호출이 실패하거나 20초 안에 응답이 없으면 THEN THE 시스템은 SHALL "조건 정리에 실패했어요. 다시 시도해 주세요"를 표시하고, 채팅은 계속 보내고 받을 수 있게 둔다. | 네트워크를 끊은 상태로 조건 정리를 실행해 안내 문구가 뜨는지, 네트워크를 다시 켠 뒤 채팅이 정상으로 오가는지 확인 |

> 확인할 동작이 더 있으면 AC-4부터 행을 추가해 쓰십시오.
> If there are more behaviors to check, add rows from AC-4.
